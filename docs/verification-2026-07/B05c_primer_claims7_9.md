# Primer fact-check — CLAIMS 7 & 9 (verified 2026-07-14)

## CLAIM 7 — NYC 2017: 230,071 filings vs 20,804 lockouts (~11:1). PARTIAL: numbers verified, ATTRIBUTION WRONG (not NYC Comptroller).
- 230,071 filings CONFIRMED: OCJ 2017 Annual Report Table 2 (p.18/PDF 25) + OCJ 2018 Table 4 (2013-2017 series: 246,864/237,639/234,270/233,884/230,071). PDFs via curl (nyc.gov 403s WebFetch): https://www.nyc.gov/assets/hra/downloads/pdf/services/civiljustice/OCJ_Annual_Report_2017.pdf ; _2018.pdf
- 20,804 = RESIDENTIAL executed evictions per NYC Council Data Team ("only 9% or 20,804 evictions were executed by the City Marshall," https://council.nyc.gov/data/evictions/) / DOI "Evictions" dataset 6z8x-wfk4 (live query: 2017 residential 20,803 + commercial 1,719; live-revised). City's official OCJ figure = 21,074 (OCJ 2017 p.17: "declining from 28,849 in 2013 to 21,074 in 2017"; source DOI via NYC Housing Court).
- Ratio holds: 230,071/20,804=11.06; /21,074=10.92 (~11:1; Council: "9%").
- CORRECT ATTRIBUTION: NYC Council Data Team (pairing); primaries = OCJ annual reports (filings) + DOI marshal data via NYC Open Data (lockouts). No Comptroller doc contains these figures.
- Caveats: petitions = nonpayment + holdover (nonpayment alone 2017 = 201,441, OCJ 2018 Table 5); Manhattan excludes Harlem; if citing City sources use 230,071 + 21,074.

## CLAIM 9 — "More than half of NY nonpayment cases unanswered -> automatic default judgment." PARTIAL: 54% CONFIRMED; "automatic" WRONG.
- Source: Brenner, Ellen, House, Lochhead, O'Regan, "Half the Battle is Just Showing Up: Non-Answers and Default Judgments in Non-Payment Eviction Cases Across New York State, 2016-2022," NYU Furman Center / HCRC data brief, Jan 2023 (full PDF read: https://www.furmancenter.org/wp-content/uploads/2023/01/Half_the_Battle_is_Just_Showing_Up_V3_1.pdf).
- CONFIRMED: "the majority (54 percent) of non-payment eviction filings go unanswered" (NY State, 64 OCA-covered jurisdictions = 83% of NYS renter households; 2016-mid-2022).
- WRONG: default is NOT automatic — "The court will not issue a default judgment without such a request [by the landlord]"; only ~20.3% of unanswered cases (11% of all filings) get default judgments; 16% of ALL filings end in default. Kernel: "In non-payment cases, courts do not hold hearings before entering default judgments."
- QUOTABLE: "a full 40 percent of issued eviction warrants across the state are the result of a default judgment."
- Period nuance: pre-pandemic non-answer ≈50% NYC / ≈40% rest-of-state; 54% is the full-period average.
- CORRECTED SENTENCE: "Across New York State courts covered by state court data (2016–mid-2022), 54 percent of nonpayment eviction filings went unanswered; roughly 20 percent of those unanswered cases — 11 percent of all filings — ended in a default judgment."
